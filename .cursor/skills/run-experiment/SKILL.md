# Run an experiment

Follow [AGENTS.md](../../../AGENTS.md). The design is in docs/plan.md, sections 3, 5 and 6.

1. Branch: `exp/<goal>` (for example `exp/e2b-iq2-at-512mib`).
2. Pin everything in the run config (`configs/experiments/<name>.yaml`):
   - the llama.cpp commit hash
   - the model's Hugging Face repo, revision and file sha256 (verify the sha256 before running)
   - the quantization, the KV-cache type, the context size and the dataset version and split
3. Run under the hard cap: `systemd-run --scope -p MemoryMax=<N>M -p MemorySwapMax=0 ...`. Record `memory.peak`, RSS and tok/s.
4. Save raw output to `results/<date>-<name>/`:
   - one JSONL line per case, holding the raw model output, the parsed prediction, the label and the timing
   - `run.json`, holding the git commit hash (`git rev-parse HEAD`, and abort if the tree is dirty), the full config, the hardware and kernel fingerprint (`orbitlog.memory.fingerprint()`) and the start and end times
5. **Never edit numbers by hand.** Summaries, tables and plots are generated by scripts from the raw files. If a run fails or crashes, record that and don't rerun until you get a good-looking number.
6. Commit as `exp(<scope>): <what was run>`, for example `exp(e1): run IQ2_M at 512 MiB on 60 test cases`. Attach the generated summary to the PR.
